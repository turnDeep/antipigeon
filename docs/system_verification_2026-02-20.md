# システム検証レポート（2026-02-20）

対象: AntiCrow リポジトリ `/workspace/antipigeon`

## 結論サマリ

- **概ね要件に一致**: Discord↔Antigravity 連携、即時実行、cron定期実行、モデル/モード切替、テンプレート管理、進捗通知、返信コンテキスト継承、allowedUserIds制御、SecretStorage(Keyring)保存は実装あり。
- **一部は「完全一致ではない」**: 添付ファイルはURL転送までで本格的な解析ロジックは未実装。`/templates` は管理のみで「テンプレートを選んで即実行」機能は未確認。`/schedules` は削除UIはあるが一時停止/再開UIは未実装。

## 項目別検証

### 1) DiscordとAntigravityを行き来する伝令システム
- BotはDiscordメッセージを受け取り、ワークスペースを解決してAntigravityClientへタスク実行を委譲する。
- 結果/進捗はEmbed更新でDiscordへ返す。
- 判定: **実装あり**。

### 2) 自然文依頼 + 即時実行 + cron定期実行
- 通常メッセージ本文をそのまま `prompt` として即時実行。
- `/schedule` でcron式を受け取り、APSchedulerに登録して定期実行。
- 判定: **実装あり**。

### 3) ワークスペース単位のDiscordカテゴリ自動作成とルーティング
- 起動時にワークスペース一覧を走査し、カテゴリと `chat` チャンネルを生成。
- 受信メッセージのカテゴリ名からワークスペースを特定して処理。
- 判定: **実装あり**。

### 4) `/models` `/mode` 切替
- `/models` は現在モデル表示＋Select UIで切替。
- `/mode` はplanning/fast切替。
- 判定: **実装あり**。

### 5) `/templates` で登録して即実行
- `list/add/remove` の管理機能はある。
- ただしテンプレートを選択して即時実行する処理は見当たらない。
- 判定: **部分一致**。

### 6) `/schedule` `/schedules` の登録・管理
- `/schedule` で登録、`/schedules` で一覧表示、Select UIで削除。
- 一時停止・再開の状態管理は未実装。
- 判定: **部分一致**。

### 7) 長時間ジョブの進捗リアルタイム通知
- `execute_task` の更新を受けてEmbedを逐次 `edit`。
- 即時実行・定期実行の双方で進捗表示あり。
- 判定: **実装あり**。

### 8) 添付ファイル解析
- 添付のURLを収集してAntigravityClientへ渡す実装はある。
- 実体の解析（OCR/テキスト抽出/型判定など）は未実装。
- 判定: **部分一致**。

### 9) Embed表示 + 返信内容の引用コンテキスト引き継ぎ
- タスク受理/進捗/結果はEmbed表示。
- 返信元メッセージ本文とEmbedフィールドを収集してコンテキストとして連結。
- 判定: **実装あり**。

### 10) セキュリティ要件
- `ALLOWED_USER_IDS` によるホワイトリスト制御あり（メッセージ/スラッシュ双方）。
- Bot TokenはKeyring（SecretStorage）から読み込み、必要時に保存可能。
- SSH公開なし・外部サーバー常駐なしはコード上で明示設定はないが、少なくともHTTPサーバー起動処理は見当たらず、Discord Botとしてローカル実行前提。
- 判定: **概ね一致（前者2つは明確に実装）**。

## 改善提案（不足分を埋めるなら）
1. `/templates run <name>` またはボタンUIを追加し、テンプレート即時実行を実装。
2. `/schedules` に pause/resume 操作と状態表示を追加。
3. 添付ファイルをダウンロード・解析するプラグイン層を追加（MIME判定、テキスト抽出）。
